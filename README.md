
# Student Management System (C++)

This is a console-based Student Management System built using Object-Oriented Programming in C++.

## Features
- Add student
- Display all students
- Search student by ID
- Save data to file

## Concepts Used
- Classes & Objects
- Encapsulation
- Constructors
- Vectors
- File Handling
- Menu-driven program

## How to Run
Compile using:
g++ main.cpp -o program
./program
